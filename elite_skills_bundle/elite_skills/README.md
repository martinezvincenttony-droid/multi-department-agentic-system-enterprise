# 5 Elite Skills for meinGPT

Drop each folder into your assistant's skills library. Each skill includes a SKILL.md (operational guide) and a Python module (executable code).

## Skills Included

1. **excel-power-updater** — Advanced Excel manipulation (update, merge, cross-reference, format)
2. **email-command-center** — Inbox triage, draft creation, digests, follow-up tracking
3. **strategic-report-generator** — Executive summaries, status reports, minutes, action trackers (Word docs)
4. **calendar-intelligence-engine** — Schedule analysis, meeting prep, conflict detection, slot suggestions
5. **data-cross-reference-gap-analyzer** — Multi-file reconciliation + color-coded Excel gap reports

## Installation

Each folder is a self-contained skill. Upload them individually to your assistant's skill library, or use the bundled ZIP.

## Dependencies

- Python 3.9+
- openpyxl
- python-docx

(All preinstalled in the meinGPT sandbox.)
