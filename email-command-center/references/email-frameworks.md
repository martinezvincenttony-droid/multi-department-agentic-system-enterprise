# Professional Email Frameworks

## The BRIEF Framework
- **B**ackground: Set context in 1-2 sentences
- **R**eason: Why you're writing
- **I**nformation: Key details, data, facts
- **E**nd: Clear call to action
- **F**ollow-up: Next steps and timeline

## Priority Classification Matrix

| Priority | Criteria | Response Time |
|----------|----------|---------------|
| P1 - URGENT | Deadline <24hrs, executive request, blocking issue | Immediate |
| P2 - HIGH | Deadline <72hrs, client-facing, significant impact | Same day |
| P3 - MEDIUM | Standard workflow, no immediate deadline | Within 2 days |
| P4 - LOW | FYI, newsletters, non-critical updates | When available |
| P5 - ARCHIVE | No action needed, reference only | Archive |

## Tone Guidelines

### Formal (Executive, External Client)
- Use full titles and formal greetings
- Structured paragraphs with clear transitions
- Professional closing (Best regards, Sincerely)

### Professional (Internal, Cross-team)
- Friendly but structured
- Can use first names
- Bullet points for clarity
- Closing: Best, Kind regards, Thanks

### Casual (Direct team, familiar colleagues)
- First name greeting
- Concise and direct
- Closing: Thanks, Cheers, Best

## Action Item Extraction Keywords
- "please", "could you", "need", "by [date]", "deadline"
- "action required", "ASAP", "urgent", "priority"
- "review", "approve", "sign off", "confirm"
- "schedule", "set up", "arrange", "book"
- "update", "revise", "modify", "change"
